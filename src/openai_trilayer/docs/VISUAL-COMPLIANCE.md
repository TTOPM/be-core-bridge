# Visual Compliance

- **Accessibility:** AA contrast minimum; keyboard focus states; semantic HTML.
- **Print-Safe:** auto print styles; black/white fallback.
- **Proof Surface:** each card shows continuity tag, truth_lock, timestamp, prompt/output hashes.
- **QR Stamp:** optional PDF stamping with a QR linking to the attestation JSON.
- **Design Tokens:** centralized in `dashboard/tokens.css` for theme discipline.
