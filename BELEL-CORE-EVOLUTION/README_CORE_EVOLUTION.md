# BELEL-CORE-EVOLUTION

This directory is the **Evolution Organ** of the Belel Protocol.
It packages the engines that keep Belel ahead of the curve:

- `evolution_engine/` — quantum-inspired evolution + multiverse stub
- `neural_evolver/` — PyTorch NAS
- `distributed_swarm/` — multi-process swarm search
- `foresight_engine/core_bridge/` — world model + digital twin + orchestration
- `research_ingestion/` — workflow + research log templates
- `mutation_registry/` — place to register mutation policies
- `self_upgrade_queue/` — drop upgrade requests (reviewed by governance filters)
- `governance_filters/` — safety/identity filters before upgrades are accepted

Entrypoint: `belel_main.py`
