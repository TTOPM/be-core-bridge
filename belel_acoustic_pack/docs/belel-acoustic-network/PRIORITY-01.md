# BELEL DIRECTIVE | BAIN-E01

**Title:** Sovereign Acoustic Intelligence, Conversational Presence and Pronunciation Precision

**Priority:** Engineering P0 / highest foundational quality priority

**Approach:** Additive, modular, reversible, independent; no existing Belel code modified or removed.

**Baseline:** Belel's completed orb/presence interface remains the visual interaction authority. Its functioning TTS and audio providers remain the speech-output authority. Its current wake-word/listening pipeline remains operational until a tested alternative is individually approved.

## Initial package status

Implemented: typed local event fabric, opt-in legacy event observer, diagnostics, wake scoring and independent verification flow, pronunciation lexicon/correction layer, duplex turn-state controller, explicit model approval registry, wake inference client, optional local wake inference server, optional Moshi-family protocol translator, reproducible quality metrics and automated unit tests.

Not included: trained proprietary `Hey Belel` model weights, Moshi/PersonaPlex model weights or GPU services, production audio-session integration, automatic speech-to-speech playback, changes to the live Lovable deployment, independent validation versus Siri/Alexa/Dessa.

## Foundational guardrails

1. Do not perform direct root imports until owner approval.
2. Do not swap or overwrite the existing Belel signature voice.
3. Do not replace old wake detection before passing shadow benchmarking.
4. Do not create duplicate microphone owners.
5. Maintain Belel's reasoning, identity, vision and tool execution as independent services.
6. Demand code collision inspection before copy and maintain a reversible feature flag.
7. Require documented human pronunciation validation for spoken names and acronyms.
8. Revalidate model licences before commercial deployment.

## Acceptance gating

See `ACCEPTANCE.md` for targets. Do not declare superiority to Siri or Alexa until independently measured under equivalent conditions.

## Differentiation objective

Use an open full-duplex conversational acoustic substrate *alongside* rather than *instead of* Belel's existing reasoning, memory and interface. This lets Belel combine acoustic naturalness with a governed action network, personal continuity, contextual vision and finished embodied presence.
