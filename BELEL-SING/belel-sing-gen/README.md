# Belel-Sing-Gen: Sovereign Music Generation Engine

Advanced, open-source toolkit for end-to-end music creation, training, and extension. Built for sovereignty, efficiency, and cutting-edge features beyond ACE-Step.

## Installation
1. Clone: `git clone https://github.com/TTOPM/be-core-bridge`
2. cd `BELEL-SING/belel-sing-gen`
3. `pip install -r requirements.txt`

## Usage
- Inference: `python belel_infer.py --prompt "Sovereign ballad" --dynamic --low_vram`
- Training: `python belel_trainer.py --dataset your_data_path --belel_lora`
- Demo: `python belel_demo.py --auto_evolve 2`

## Features
- Auto-evolution, emotion synth, genre fusion, real-time streaming.
- Integrations: Spotify, NFT, Mubert, LALAL.
- Low-VRAM, multi-language, MIDI export.
